## 3. Interpretation controls

- Each candidate remains EXTRACTED — REVIEW PENDING.
- No candidate is approved, assigned priority, assigned owner or finally allocated to a phase.
- Numeric thresholds are not invented where the source requires targets to be set later.
- A source requirement to specify or demonstrate something is distinguished from the eventual technical design choice.
- The source's explicit recommendation language is not promoted to mandatory language.
- Candidate overlap with earlier records is retained for semantic review; no ID is silently deleted.
- Legal/administrative authorization is not conflated with technical homologation.
