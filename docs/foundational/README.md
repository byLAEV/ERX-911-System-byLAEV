# FOUNDATIONAL SOURCE FILES — CUSTODY README

This directory is reserved for immutable original source files used by ERX byLAEV.

## Rules

- Store original source files without editing, re-exporting, translating, or renaming them.
- Preserve the original supplied filename.
- Record the document's internal identifier and version separately from its filename.
- Verify SHA-256 after archival and record the repository path and commit in the foundational material register.
- Store translations, OCR output, extracts, annotations, and derivative documents outside the original-source collection.
- Never treat a derivative as a replacement for its source.

## Current status

The five source PDFs used to prepare the initial WP-0.2 inventory baseline were inspected in the working conversation environment. Their checksums are recorded in:

`registers/foundational-material-register.csv` and
`docs/foundational/ERX-FOUNDATIONAL-MATERIAL-REGISTER-001.md`.
