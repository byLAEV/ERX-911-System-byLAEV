## 1. Purpose and limits

This proposal replaces the stale 65-candidate scope and repairs mismatched generic verification language by deriving a **verification approach appropriate to each candidate's stated subject**. It does not establish source wording, approve requirements, select implementation technology, invent numeric thresholds, claim tests were run, or authorize development.

For each candidate:
- The candidate statement and locator are copied from the canonical register.
- Existing source-derived criterion is preserved as recorded.
- The proposed criterion is a review prompt, not an acceptance oracle.
- Exact normative modality, source fidelity, quantitative thresholds and authority scope require review.
- Criteria for 17 late-extraction candidates are explicitly marked pending; they are not fabricated to appear complete.
