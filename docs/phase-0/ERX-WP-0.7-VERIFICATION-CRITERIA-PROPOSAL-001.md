## 1. Purpose and limits
This proposal provides a candidate-specific verification approach for each source candidate. It does not approve requirements, establish source wording, select implementation technology, invent numeric thresholds, claim tests were run, or authorize development. Criteria are proposed acceptance or inspection outcomes; methods are not execution evidence. Any unresolved source modality or specification gap remains open.
